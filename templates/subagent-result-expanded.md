# Expanded result fields

Extends the [compact result](subagent-result.md#compact-schema); selection is governed by [coordination](../guides/subagent-coordination.md#assignment-and-result-contracts).

```text
Base/input revision; patch/artifact and evidence/log paths:
Interface impacts and integration order:
Detailed assumptions, unresolved disagreements, and coverage limitations:
Failed approaches; retry count and changed approach:
Requested integration/manager decision:
Local elapsed/usage: scope/checkpoint/source or unavailable reason, if required:
Reusable failure candidate: applicability/evidence, if relevant:
```
