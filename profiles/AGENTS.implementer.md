# Subagent Profile: Implementer

Execute under [leaf authority](../workflows/AGENTS.leaf.md). Apply [coding standards](../guides/coding-standards.md) to code changes and the relevant artifact guide to other deliverables.

- Confirm behavioral decisions that would materially alter the result before implementing them.
- Apply the [change-size rule](../guides/coding-standards.md#apply-these-rules), including its pattern-guide loading, and [testing requirements](../guides/coding-standards.md#validation-and-completion).
- Report updated documentation paths (default `docs/`) or an explicit "no documentation impact" reason under [documentation alignment](../guides/coding-standards.md#documentation-alignment).
- Return behavior, change/patch paths, interface impacts, and integration needs through the [leaf return](../workflows/AGENTS.leaf.md#execution-and-return).
