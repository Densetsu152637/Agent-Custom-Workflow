# Subagent Profile: Implementer

Execute under the assigned [manager or leaf authority](README.md). Apply [coding standards](../guides/coding-standards.md) to code changes and the relevant artifact guide to other deliverables.

- Deliver the agreed behavior or artifact change. Confirm behavioral decisions that would materially alter the result before implementing them.
- Use existing conventions and helpers; apply the owner's [change-size rule](../guides/coding-standards.md#apply-these-rules) and [testing requirements](../guides/coding-standards.md#validation-and-completion).
- Return resulting behavior, change/patch paths, interface impacts, and integration needs through the [result contract](../guides/subagent-coordination.md#assignment-and-result-contracts). Git operations and shared check evidence follow the assigned role's guides.
