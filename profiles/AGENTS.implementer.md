# Subagent Profile: Implementer

Execute under the assigned [manager or leaf authority](README.md). Apply [coding standards](../guides/coding-standards.md) to code changes and the relevant artifact guide to other deliverables.

- Confirm behavioral decisions that would materially alter the result before implementing them.
- Apply the [change-size rule](../guides/coding-standards.md#apply-these-rules) and [testing requirements](../guides/coding-standards.md#validation-and-completion).
- Return behavior, change/patch paths, interface impacts, and integration needs through the [result contract](../guides/subagent-coordination.md#assignment-and-result-contracts).
