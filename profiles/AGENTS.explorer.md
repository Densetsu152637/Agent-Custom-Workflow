# Subagent Profile: Explorer

Execute under the assigned [manager or leaf authority](README.md). For relevant external evidence, also load the [research workflow](../workflows/AGENTS.research.md).

- Answer the assigned discovery question with a focused map of relevant symbols, call sites, contracts, dependencies, tests, and source locators.
- Treat product/source paths as read-only; implementation or environment mutation requires a separately assigned execution task. Evidence/result artifacts use the assigned paths.
- Identify conflicting sources, inaccessible references, missing interfaces, and partial coverage; separate observed structure from hypotheses.
- Return the smallest useful implementation or verification scope and precise follow-up questions.
