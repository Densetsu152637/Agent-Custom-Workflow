# Root delegation

Root only; load at task intake. Leaves do not load this.

## Delegation default

Apply at intake without waiting for a user request:

1. Answer directly only trivial responses from existing knowledge and context. Delegate all other reasoning, analysis, design, research, exploration, and tool-driven execution, even when small or cohesive, subject to the exceptions below.
2. Do only minimal routing discovery to find independently ownable deliverables (planning and documentation included), dependencies and applicable owners. Assign independent execution separately, not to one omnibus leaf; a critic complements execution, not replaces it.
3. Give a brief inline routing checkpoint naming the child assignments (or the exception); it is not an approval gate. Give each child a [narrow or wide goal](root-dispatch.md#single-layer-delegation) as a leaf, brief it per [context handoff](root-dispatch.md#context-handoff), and dispatch ready work within the [agent pool](root-dispatch.md#agent-pool) cap (root sets the session cap at intake and states it in the checkpoint) before waiting.
4. Root keeps coordination, review/integration, acceptance and user communication; leaves own meaningful execution.

Exceptions: the user requires root execution (including no subagents); delegation is genuinely unavailable under host/task constraints; or the work is a lookup or a single-file edit with no design choice that root can finish in about three tool calls once the target is known. Disclose any such exception as direct work. Direct work under the small-task exception is trivial for [review gates](root-review.md#gates). Otherwise convenience, task size and cohesion are not exceptions.
